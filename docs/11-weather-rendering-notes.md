# 天气页面渲染说明

天气页面包含小时预报、多日预报、城市候选和多种天气图标。在 Windows / MSVC 环境下，首次创建复杂页面时可能出现明显的首帧延迟。

当前实现做了以下处理：

- 页面通过异步 Loader 创建，降低主界面切换时的阻塞；
- 城市候选模型在下一轮事件循环初始化；
- 天气图标使用项目内 PNG 资源，不依赖彩色 Emoji 字体；
- 高德行政区请求限制返回层级，避免一次解析过大的嵌套 JSON；
- 页面加载失败时通过 Toast 提示查看 QML 日志。

需要排查场景图问题时，可临时在运行环境中加入：

```text
QSG_INFO=1
QT_LOGGING_RULES=qt.scenegraph.general=true;qt.rhi.*=true
```

如果问题只出现在默认图形后端，可临时使用：

```text
QSG_RHI_BACKEND=opengl
```

这些变量只用于定位，不作为项目默认配置。
