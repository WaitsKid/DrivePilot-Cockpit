# 07 用户使用说明

## 7.1 首页与应用

- 首页卡片可进入空调、音乐、地图、车辆和 AI 助手；
- 应用中心支持搜索、类别筛选、收藏和常用排序；
- 返回、主页、旋转和关机按钮位于系统框架区域。

## 7.2 空调

- 左右温度可独立调整；
- 风量支持 0～10 档；
- 模式支持正常、除湿、加强和自动；
- 控件状态会同步到首页快捷区和 AI Agent 工具状态。

## 7.3 控制中心与车辆设置

- 可切换 WLAN、蓝牙、定位等模拟开关；
- “疲劳驾驶提醒”关闭后，DMS 状态栏图标和告警立即消失，后台摄像头停止；
- 再次开启后 Qt 自动恢复连接并请求启动监测。

## 7.4 音乐与视频

- 音乐支持播放、暂停、上一首、下一首、音量和本地导入；
- 视频中心支持本地视频列表和播放；
- 用户导入文件属于运行时数据，不应上传到 GitHub。

## 7.5 天气

1. 打开天气页面；
2. 点击城市选择按钮；
3. 输入省、市、区或县名；
4. 从行政区建议中选择；
5. 查看当前、小时和多日预报。

## 7.6 地图导航

1. 配置高德 Key；
2. 搜索目的地；
3. 选择候选地点；
4. 发起路线规划；
5. 查看导航步骤和地图移动。

本项目是模拟导航，不用于真实驾驶决策。

## 7.7 联系人与电话

- 添加、编辑、删除和搜索联系人；
- 使用拨号盘模拟呼叫；
- 生成本地通话记录；
- 数据保存在运行时 SQLite，不随仓库发布。

## 7.8 Vector Studio

- 选择矩形、椭圆、线条、自由绘制或文字工具；
- 调整描边、填充和层级；
- 使用选择工具拖动和编辑；
- 导入/导出文件时注意本地路径权限。

## 7.9 DMS 疲劳监测

Qt 不显示摄像头画面。状态栏图标含义：

| 图标 | 状态 |
|---|---|
| 绿色 | 活力充沛 |
| 蓝色 | 状态正常 |
| 黄色 | 略微疲劳 |
| 红色 | 严重疲劳 |

出现新告警时：

- 全局 Toast 显示闭眼时长、PERCLOS 和哈欠次数；
- TTS 播报一次；
- 同一 `event_id` 不会重复播报。

## 7.10 AI Agent

支持键盘和讯飞语音输入。推荐测试：

```text
把空调调到22度并打开空调页面
播放下一首，音量调到45
关闭疲劳驾驶监测
打开蓝牙并进入车辆设置
```

界面会显示当前处理状态、待执行的车控操作、Qt 返回的实际结果和最终回复。

## 7.11 正确退出

- 先关闭 Qt；
- 在两个 Python 终端按 `Ctrl+C`；
- 确认摄像头指示灯关闭；
- 不要提交运行时数据库、日志、媒体和配置。
