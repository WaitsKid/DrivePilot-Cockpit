# 08 测试与质量保证

## 8.1 测试策略

项目采用四层测试：

1. 单元测试：标签、指标、状态机、协议和工具描述；
2. 集成测试：FastAPI REST/WebSocket、模型加载、Qt 工具结果回传；
3. 模型评估：独立测试集、混淆矩阵、阈值选择和 ONNX 一致性；
4. 人工端到端：三个进程、摄像头、网络服务、页面和语音。

```powershell
cd agent-backend
pytest -q
```

- 配置占位值识别；
- 本地规则工具解析；

- WebSocket 核心逻辑。


### DMS

```powershell
cd dms-backend
pytest -q
```

测试覆盖：

- 标签定义；
- MobileNetV2 输出形状；
- 风险阈值选择；

- ROI 裁剪；
- DMS API 合同；
- 疲劳状态机；
- 状态存储；
- 分类指标。

自动测试覆盖配置、协议、阈值、ROI、状态机和 API 合约。模型训练与摄像头联调需要在本地环境单独执行。

## 8.5 缺陷分级

| 等级 | 说明 | 示例 |
|---|---|---|
| P0 | 安全/隐私/无法启动 | Key 泄露、摄像头无法释放 |
| P1 | 核心功能失败 | Agent 无法执行工具、DMS 无状态 |
| P2 | 部分功能或明显体验问题 | 页面闪烁、错误提示不准确 |
| P3 | 视觉和非核心优化 | 间距、文案、轻微动画问题 |

## 8.6 发布前我的检查

1. Agent 与 DMS 的 Python 测试通过；
2. Qt 在干净构建目录中完成配置和编译；
3. `config.json`、`.env`、运行时数据库和日志未进入 Git；
4. 仓库中不包含训练数据、个人摄像头数据或大型模型产物；
5. README 中的路径、截图和启动命令可以正常访问。
