# DrivePilot Agent 说明

## 输入

- 用户输入的文本；
- 讯飞 ASR 返回的最终文本；
- 当前会话消息；
- Qt 返回的工具执行结果。

## 输出事件

- `analysis`：面向界面的简短处理状态；
- `plan`：准备执行的工具列表；
- `tool_call`：结构化 Qt 操作；
- `observation`：Qt 返回的实际执行结果；
- `final`：最终文本回复。

## 可用工具

- 读取车辆状态；
- 打开页面；
- 设置空调温度、风量和模式；
- 控制音乐和音量；
- 切换部分车辆设置；
- 显示全局提示。

## 约束

- 工具名使用固定白名单；
- 参数使用 JSON Schema；
- Qt 侧再次进行范围检查；
- `call_id` 用于关联一次工具调用和结果；
- 支持超时、取消、会话重置和最大轮数；
- 云模型不可用时可切换到本地规则服务。

用户文本可能发送到所配置的云模型。摄像头画面不会发送给 Agent，密钥保存在未提交的 `.env` 中。
