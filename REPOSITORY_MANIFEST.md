# Repository Manifest

## Included

- final Qt/QML/C++ HMI source code;
- required QML, UI, local weather icon and demo audio resources;
- root-level interface screenshots used by the GitHub README;
- DMS training, evaluation, inference and FastAPI source code;
- AI Agent FastAPI/WebSocket source code;
- example configuration files;
- pytest tests;
- software engineering documentation;
- GitHub Actions and Issue templates.

## Excluded

- `hmi-client/config.json`;
- `agent-backend/.env`;
- Kaggle dataset;
- personal images, webcam captures and recordings;
- PyTorch checkpoints and ONNX model binaries;
- YuNet model binary;
- runtime SQLite databases and QSettings data;
- user-imported music and video;
- `.venv`, IDE metadata and CMake build directories;
- historical incremental ZIP packages.

## Reason

The excluded files are secrets, personal/runtime data, reproducible generated outputs, large binaries, or materials whose redistribution license requires separate confirmation.
